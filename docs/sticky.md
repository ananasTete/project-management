
### 冻结列

1. 表头默认为冻结行
2. 默认第一列为冻结列
3. 在右键菜单可设置或取消设置冻结列
4. 冻结列右侧列自动成为冻结列；取消冻结列（点冻结区内的第 N 列）：边界 = N-1（该列及其之后全部解冻）
5. 设置之前检测当前列及其之前所有列宽之和是否小于容器宽度，是则允许设置，否则不允许设置，并通过 toast 提示用户。因为大于容器宽度下设置冻结列无意义。


### 行高

1. 设置 4 档行高，low/meduim/high/max 四档，默认 low，可在页面 header 切换高度。
2. 表格数据结构新增 rowHeight 字段

| 层 | 职责 | 内容 |
| --- | --- | --- |
| td（共享壳） | 高度与边界 | 固定高 40/60/80/100px（box-border，含 1px 底边框）、水平 px-3、边框背景、overflow-hidden |
| 内容组件（共同约定） | 占位方式 | h-full + 垂直居中（flex items-center），所有 type 统一 |
| 各 type（自主区） | 怎么渲染 | text 用 line-clamp-N 省略；多选/附件自由 wrap，超出被壳裁剪；数字右对齐；date 走和 text 同款 clamp |

### cell 选中，移动与快捷键

| 键 | 编辑器内 | 选中态（非编辑） |
| --- | --- | --- |
| Enter | 提交并下移 | 下移 |
| Shift+Enter | 换行 | 插入换行 |
| Tab / Shift+Tab | 提交并右移 / 左移 | 右移（换行到下一行第一个） / 左移（换行到上一行最后一个）|
| Cmd/Ctrl+Enter | 编辑器换行 | — |
| Esc | 取消编辑进入选中态 | - |
| F2 | — | 进入编辑 |
| 可打印字符 | — | 替换式进入编辑 |
| Delete/Backspace | 正常删除 | 清空选中格（提交 ""）并退出选中态 |
| 方向键 / Shift+方向键 | 光标移动（不拦截） | 移动 / 扩展选区 |
| Cmd+A | — | 全选（selectAllCells） |
